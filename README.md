# Гирлянда на ATmega328P

## 📌 Описание
Учебный проект на микроконтроллере **ATmega328P**.  
Управляет 8 светодиодами, подключёнными к порту D. Реализованы два режима:
- **Мигание** — все светодиоды одновременно включаются и выключаются.
- **Бегущий огонь** — светодиоды загораются по очереди.

Переключение режимов — двумя кнопками на порту B.  
Проект собран и проверен в симуляторе **Proteus**.

## 🧰 Компоненты
- Микроконтроллер **ATmega328P**
- 8 светодиодов (LED-RED)
- 8 резисторов **300 Ом** (токоограничивающие)
- 2 тактовые кнопки
- Провода, макетная плата (или Proteus)

## ⚙️ Принцип работы
- В `setup()` настраиваются порты:
  - `DDRD = 0xFF` — все пины порта D на выход.
  - `DDRB = 0x00` — порт B на вход.
  - `PORTB = 0xFF` — включаем внутренние подтягивающие резисторы.
- В `loop()` проверяется состояние кнопок:
  - Нажата кнопка на **PB0** → все светодиоды мигают (период 300 мс).
  - Нажата кнопка на **PB1** → запускается «бегущий огонь».
  - Если кнопки не нажаты → светодиоды выключены.
